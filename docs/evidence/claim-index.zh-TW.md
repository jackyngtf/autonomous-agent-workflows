## 未沿用的說法

已檢視檔案不足以支持「每個 Agent 超過 60 次無人執行」、連續成功紀錄、經量度的一小時縮短至數秒、固定安全恢復期限，或全面逐位元組保留。不採用這些說法，不代表它們不可能成立，而是反映本案例現有證據的範圍。

離線示範有獨立的程式及測試。即使合成範例重現類似故障，也不能把表中的歷史結果改標成「已重現」。
