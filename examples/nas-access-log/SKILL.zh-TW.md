# NAS 報表：入口指引

[English](SKILL.md) · [**繁體中文**](SKILL.zh-TW.md)

> 公開設計參考。不提供真實 API 或 SMB 設定。可執行的合成範例請使用[離線示範](../../demo/README.zh-TW.md)。

處理前閱讀 [WORKINSTRUCTION.md](WORKINSTRUCTION.zh-TW.md)，確認授權範圍、實際來源約定、截止日期及支援的目的地格式。先讀現行規則，再於特定錯誤或疑問令歷史事件相關時搜尋。

## 預期任務行為

- 使用 `Australia/Melbourne` 計算已完成日期，排除目前本地日期。
- 檢查目的地已涵蓋日期，不假設上次報告完整。
- 區分已確認不存在的檔案，以及存取或解析失敗。
- API 達回傳上限、未正確篩選或其他不確定回應，應視為完整性問題。
- 發佈前，按獨立準備的預期資料驗證既有及新增紀錄。
- 正式連接模組應取回並驗證已發佈副本。
- 遇到日期涵蓋範圍不明、紀錄衝突或超出授權的決策時，停止並報告。
- 操作摘要不應包含憑證、token 或可識別的檔案路徑。

歷史日期分組及假期規則，應列為明確政策，不應由 agent 臨時推測。某日期沒有資料，應與查詢失敗或結果不完整區分。

## 報告與知識

記錄執行模式、來源涵蓋範圍、規劃日期、實際變更、驗證範圍及未解決缺口。[合成報告](sample-report.zh-TW.md)展示這些欄位，不是正式結果。

新發現應附上日期及來源。程序修改須維持在任務權限內。月底文件維護應有獨立完成紀錄；文件處理失敗，不應導致已完成匯出重新執行。

本文描述預期限制。技術強制措施、正式憑證及恢復程序，屬於另外的部署責任。
