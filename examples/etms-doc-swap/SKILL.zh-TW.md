# eTMS 替換：入口約定

[English](SKILL.md) · [**繁體中文**](SKILL.zh-TW.md)

> 按現有入口指引重新編寫的參考，不是可執行的部署設定，也不包含連線細節。本文不能驗證 engine 行為或已完成執行。

預定排程於平日 09:30 執行，來源沒有訂明時區。任務目的是將收到的文件更新交由預先建立的 engine 處理，再報告結果。交接流程及證據邊界詳見[程序參考](WORKINSTRUCTION.zh-TW.md)。

## 權限與限制

- 透過獲授權的外部儲存位置取得必要 engine、driver 及設定。如果檔案缺漏，停止並報告 engine 尚未部署。
- 按設定模式執行。Shadow 只規劃及驗證，不寫入正式環境。切換 live 由操作負責人決定；agent 不得自行切換。
- 只經 engine 或 driver 執行計劃內檔案變更、版本封存及指定日誌或報告，不得臨時手動替換。
- 不得存取資料庫、使用資料庫憑證或執行 SQL。由靜態快照產生的檔案 manifest，不代表獲准查詢資料庫。
- 不得修改版本欄位、培訓進度、完成紀錄、指派、測驗、資料庫參照、應用程式碼或容器設定。重新培訓決策不屬於任務範圍。
- 失敗或含糊情況下停止並報告。不得靜默重試失敗的 live 寫入，也不得自行修補資料庫參照。
- 輸出與報告不得包含憑證或內部連線資訊。

## Driver 結果與報告

閱讀 driver 結構化輸出及最新報告，按其回傳的 `PLANNED`、`SWAPPED` 或 `HELD` 狀態及原因彙整輸入處理情況。指出提交團隊或操作負責人需要採取的行動、無法使用的 manifest 目的地、部分完成情況及 engine 錯誤。

Live 模式下，在獲授權的私人報告記錄每項回報的替換及其舊版本封存。如果 driver 當機，報告錯誤及最後已知狀態，不得改用手動替代操作。

回復是交由 engine 負責的約定要求。未有支持輸出時，agent 不應聲稱回復成功；本公開參考亦不聲稱回復曾經通過測試。
