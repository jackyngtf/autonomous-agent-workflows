# eTMS 替換：交接程序參考

[English](WORKINSTRUCTION.md) · [**繁體中文**](WORKINSTRUCTION.zh-TW.md)

本文區分預期交接流程與 **2026 年 9 月 22 日**的部署／原始碼檢視。該次唯讀檢查已確認 driver、engine 及設定檔，快照中的模式為 **shadow**，沒有執行操作程式。另行評估的使用者手動 shadow 報告記錄 30 HELD、0 PLANNED、0 SWAPPED。私有實作仍不在公開 repository 內；下列程序不代表所有要求已經獲實作強制執行。

## 輸入與部署邊界

任務預期有一個待更新文件資料夾，以及可從獲授權外部儲存位置取得的部署 engine 套件。套件提供 driver 及設定。由靜態 SQL 快照產生的 manifest，是 engine 使用的檔案輸入；任務仍禁止連接資料庫或執行 SQL。

指引指定平日 09:30 執行，未列明時區。部署負責人需要確認排程及存取細節。本公開參考省略主機、帳戶、憑證、共享位置及內部檔案系統路徑。

## 交接次序

| 步驟 | 約定 | 失敗或不確定時 |
|---|---|---|
| 1. 取得部署套件 | 經授權存取取得預期 engine、driver 及設定 | 缺少必要檔案時報告「ENGINE NOT DEPLOYED」並停止 |
| 2. 遵守設定 | 使用設定的 shadow 或 live 模式，不修改模式 | 不自行推定可以啟用 live |
| 3. 呼叫 driver | 將規劃、驗證及獲准替換交予預先建立的實作 | 報告當機及最後已知狀態，不手動替換 |
| 4. 檢查結果 | 閱讀結構化輸出及最新報告 | 保留部分完成、失敗及未明狀態，不虛構成功 |
| 5. 報告處理情況 | 解釋已規劃、已替換及暫緩輸入、原因與後續行動 | 含糊情況下停止；不在未報告前重試失敗的 live 寫入 |

## 模式與可執行變更

**Shadow：**快照設定選用此模式。入口約定描述只規劃及驗證、不修改正式環境。已檢視原始碼會跳過正式文件替換，但 driver 在模式分支之前會清理收件區的隱藏、暫存或中繼資料項目，也會在 shadow 上傳報告。因此，此模式不保證完全沒有遠端變更。以上是程式層面的行為，不代表已在某次執行觀察到特定項目被刪除。

**Live：**預期約定只允許 engine 計劃內的檔案替換，以及獲授權的相關封存、日誌及報告寫入。Engine 負責替換及要求的回復行為。靜態原始碼檢視不能證明原子性、回復可靠性或任何成功的正式結果。

Agent 不得以手動複製檔案或修改資料庫參照，補救 driver 失敗。資料庫版本欄位、培訓紀錄、進度、完成紀錄、指派、測驗、應用程式碼及容器設定，均不屬於範圍。文件檔案替換，不應被描述為更新了這些紀錄。

## 影響結果解讀的程式發現

Driver 不傳遞首次 engine 子程序結束碼，JSON 缺漏時可能改用空結果；其 shadow 分支會回傳零。應獨立閱讀報告內容及逐項狀態。在已檢視程式中，`HELD` 代表事前檢查停止，`ERROR` 代表捕捉到處理例外。兩者都不應因外層程序回傳零，而被描述為完成替換。

首次規劃亦依賴目的地檔案，但 driver 又按該規劃結果下載這些檔案。隔離跟進已重現這項初始化失敗，並以模擬 PDF 中繼資料及阻止傳輸的方式測試私人候選版本。[部署檢視](../../docs/evidence/etms-deployment-review-2026-09-22.zh-TW.md)區分已檢視部署、暫緩執行、22／22 遠端目標檢查、離線候選結果及其後核實的部署。

## 報告約定

私人操作報告應記錄：

- 設定模式及 driver 結果，包括當機或部分完成狀態。
- 每個輸入回報的 `PLANNED`、`SWAPPED` 或 `HELD` 處理狀態及原因。
- 提交團隊或操作負責人需要解決的事項。
- 未通過預期可用性檢查的 manifest 目的地，以及 engine 錯誤。
- Live 模式下，回報的已替換檔案及相應封存檔名。
- 任何回復嘗試及回報狀態，不以沒有訊息推定成功。

這些是預期欄位，不是虛構的執行範例。私人報告可能需要內部檔案識別資訊；如要公開作為證據，需另外整理及去識別。

## 支持更強說法所需的證據

部署檔案、設定及部分程式路徑現已檢視；要評估規劃、獲准變更及恢復，仍需受控執行證據及失敗測試。要聲稱完成正式替換，還需要獲授權的執行紀錄及前後證據。已評估的使用者手動 Cowork 嘗試仍屬暫緩的 shadow 結果。它與離線候選檢查均不能證明排程成功或 live 替換。修正其後已部署並核對摘要值，設定維持 shadow；修正後的 Cowork 執行仍待觸發。
